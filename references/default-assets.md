# Default materials

- assets/default.glb: neutral bind-pose default character, two skinned meshes, 65 bones and no built-in animation; copied from the user-selected default model and bundled here for standalone use.
- assets/defaults/source.mp4: user-selected default video 198749558-1-208.mp4, movie/audio duration 22.395 seconds.
- assets/defaults/dancer.bvh: existing body/finger capture for that exact video; reuse does not submit a new paid task.
- assets/defaults/avatar.glb: the same default character with that capture already baked as one animation. Use this derivative for the all-default route; use default.glb when applying a different video's motion.
- assets/defaults/track.json: example timing, automatically estimated near 109 BPM. Recalibrate for different music. Existing ground repair may suppress jumps.

The local default materials are user-selected task assets, not covered by MIT and not a grant of public redistribution rights. They require no sibling skill or machine-specific absolute path. Selecting the defaults authorizes local reuse for this requested workflow; it does not silently authorize public hosting or repository exposure. Do not replace uploaded models or video with defaults unless the user chose that route.
